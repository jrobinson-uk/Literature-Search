Citation Crawl v2BETA — pipeline runs Keyword pass → Backward pass → Forward pass. Runs alongside (not instead of) the original Citation Crawl, in its own sheet.

1. Seeds

By default, seeds come entirely from the keyword pass (Phase 1) below — it searches Semantic Scholar using your filter terms and keeps whatever passes the filter. Hand-picking specific papers here is optional and adds them on top of (not instead of) the keyword pass's own discoveries.

2. Pipeline Settings ▶

Name this crawl — it becomes the sheet tab name.

Phase 1 — Keyword pass. Target number of seed papers to collect via Semantic Scholar search before moving to the backward pass. Combines terms across your positive filter groups below into search queries automatically.

NOT-groups no longer exclude outright. A paper that matches every positive filter group is kept even if a NOT-group also matched — the row highlights orange instead of green, and the Filter Match cell gets a note explaining why, rather than the paper being silently dropped or its title being altered.

Backward pass runs to the same "Max depth" as the forward pass (not a separate, smaller cap) — only papers whose Filter Match is TRUE expand backward, matching the forward pass's own gate.

Abstract resolution stays Semantic Scholar + OpenAlex only, but persists for longer (more retries per lookup) and runs one final retry sweep over any still-missing abstracts before the run completes.

3. Filter ▶

Each card is an AND condition; terms within a card are OR'd. Tick NOT for a group whose hits get flagged rather than excluded (see above). At least one non-NOT group with terms is required — the keyword pass searches on these.

4. v3 Options BETA ▶

Everything below is additive and off by default — leaving all of it unchecked reproduces today's pipeline exactly (keyword → backward → forward).

Enumerates the full publication record of these venues (comma or newline separated — matched fuzzily against Semantic Scholar's own venue names) within the year window, through the same filter. Pre-filled with the brief's a-priori list; add more venues from your own prior runs as needed.

If the keyword pass collects fewer seeds than this percentage of the target, the crawl stops with a "Shortfall" status instead of silently continuing to backward/forward with a thin seed set — click "Resume v2 Crawl" to continue anyway once reviewed.
