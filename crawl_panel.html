1. Find Seed Papers

Enter a title, DOI, OpenAlex ID (W...), ArXiv ID, or Semantic Scholar URL / ID. To add multiple papers at once, paste a comma-separated list of IDs.

2. Crawl Settings ▶

Name this crawl — it becomes the sheet tab name.

Unticking "Only log matching papers" also records every paper the crawl looks at but rejects, marked as already-crawled so they aren't expanded further — useful for auditing why a paper didn't make it in. Costs no extra API calls, just extra rows.

3. Filter ▶

Only papers whose abstracts match this filter are added to the sheet. Each card is an AND condition; terms within a card are OR'd. Tick NOT to exclude matches.
